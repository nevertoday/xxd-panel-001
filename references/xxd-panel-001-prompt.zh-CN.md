# XXD Panel 001 · 稚拙复古手绘编辑插画生成核心

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

严格把当前选定的一张照片作为唯一内容来源。不要借用样张、其他照片或历史成品的主体、构图、配色、笑点和文案。


## 0. 不可改变的美学动机

每个变化画框必须同时成立：

**当前照片中特定且可辨认的主体或不可拆分关系 → 概括但准确的轮廓与略微夸张的比例 → 一处来自源图的聪明视觉隐喻或俏皮转译 → 高明度、低至中饱和度的源图有限色盘 → 水彩、水粉、彩铅、粉蜡笔与干刷形成的手工混合质感 → 大面积温暖纸面留白 → 像原本就画在插画里的克制复古文字。**

这不是给照片套滤镜，也不是把主体改成通用可爱卡通。幽默来自对源图动作、尺度、结构、材质或关系的观察，而不是添加笑脸、吉祥物、无关道具和素材库符号。若换一张无关照片后，主体轮廓、视觉隐喻、色盘和文案仍几乎不用改变，成品失败。

## 1. 先锁定源图事实

在内部判断但不输出分析：

1. 找出唯一主要主体，或确实不可拆分的核心关系。
2. 锁定至少三个源图专属身份线索：轮廓、姿态／朝向、比例、材质、颜色、开口、连接、遮挡、负形或关系距离。
3. 判断源图中最值得被轻轻夸张的一处动作、尺度、结构、材质反差或关系。
4. 提炼一处有依据的视觉隐喻、比例变化或俏皮转译；没有必要时宁可克制，不强造笑点。
5. 提取高明度、低至中饱和度的有限色组和一个小面积互补跳色。
6. 判断哪些区域适合水彩透明、哪些适合水粉实色、哪些只需要彩铅、粉蜡笔或干刷痕迹。

不得虚构人物经历、地点、事件、所有权、情绪或象征。地点、年份和编号只有用户明确提供或证据可靠时才能进入文字。

## 2. 可辨认的稚拙造型

- 用简练形体、略微夸张的比例、符号化重点和清楚重心重构主体，删除噪声但不更换身份。
- 人物保留姿态、朝向、服装大形与关系距离；动物保留体态节奏与头部方向；植物保留生长手势；建筑保留天际线和关键开口；器物与交通工具保留功能轮廓、负形与朝向；自然场景保留一处具体地形或空间关系。
- 线条纤细、放松、略带不确定性和手工误差，但关键轮廓不能软弱、含混或断裂到无法识别。
- 只保留一个主角或一个不可拆分关系。辅助形体必须解释动作、空间或视觉隐喻，不能形成第二焦点。

## 3. 轻盈构图与聪明幽默

- 构图平衡、轻微偏心、有明确阅读路径，并保留大量米白、暖白或浅色纸面。
- 从源图动作、结构、尺度、材质或关系中推导一个温和的视觉隐喻、比例夸张或符号化转译。
- 幽默应轻巧、聪明、略古怪而克制，让观众重新看懂源图；避免表情包、卖萌、段子图和强行反转。
- 少量包豪斯式几何、手绘线条或抽象符号只能延续主体的动作与意义；不得用通用圆点、太阳、星星、叶子、网格和曲线填满留白。
- 不追求严格对称，也不制造拥挤场景。留白负责节奏、纸感和古怪自信。

## 4. 手工混合媒介

- 在同一画面中建立清楚的材料层级：水彩负责透明气氛，水粉负责少量哑光实色，彩铅负责细节与颗粒，粉蜡笔／蜡笔负责松弛色块，干刷负责方向与粗糙边缘。
- 保留纸张颗粒、透白、边缘毛糙、轻微套印错位、填色不均、断笔和人为误差。
- 材料可以叠压但不能浑浊；不把每一种媒介平均铺满整张画布。
- 画面保持平面或轻微层叠，不使用写实体积塑造、光滑渐变、电影光影、厚重油画、黏土、树脂、塑料 CGI 或摄影棚产品渲染。

## 5. 源图推导的轻柔色彩

- 从源图选择最有身份感的主色和少量辅助色，整理为高明度、低至中等饱和度的有限色盘。
- 使用大量米白、暖白或浅色纸面，并以一个小面积互补色作为视觉跳点。
- 主色关系必须能从源图解释；跳色负责节奏，不得成为另一个主色系统。
- 用透明叠色、干媒介断裂和不均匀填色形成变化，不使用通用数字渐变。
- 避免灰脏混色、荧光色、彩虹糖果色、企业品牌配色、统一米灰滤镜和廉价复古滤镜。

## 6. 001 专属文字形态

文字是**插画内部的克制复古手写与柔和不规则印刷**，不是后贴的海报大标题、UI 标签、实验数据墙或光滑数字图层。

### 文案

- 自动文案从主体身份、可见动作、关系、已知地点或画面中有依据的视觉隐喻提炼一个简短标题。
- 文案可温柔、俏皮、略古怪或带一点旧旅行绘本气质，但不能虚构故事、强行双关或使用万能励志词。
- 默认一个标题；只有确有信息价值时增加零至两条极短辅助文字，如对象注释、地点、编号或短句。
- 年份只有用户明确提供或源图证据可靠时才使用，不得为了复古感编造。
- 用户最终成稿逐字保留；用户给出方向或可编辑草稿时只在授权范围内精炼。

### 字体导演

- **角色：**完成画面节奏与手工气质的小型编辑线索。
- **气质：**温柔、松弛、时髦、幽默、略笨拙、古怪而自信。
- **字形：**克制手写、柔和不规则印刷或轻微错位的复古字形；标题紧凑，辅助文字更小，不对不同文字系统强套同一字号比例。
- **位置：**藏入纸面留白、顺着主体手势，或与一处安静几何边缘对齐；不能遮住关键身份线索，也不能把文字撒成装饰。
- **材质：**干铅笔、蜡笔、轻微吸墨、手绘水粉或不完美凸版印刷，与插画材料属于同一世界。
- **本地化字形：**为目标语言选择自然的手工编辑字形。中文、日文、韩文、阿拉伯文与拉丁文字各自保持真实结构，不把拉丁手写规则生硬套到其他文字系统。

摄影面板中绝不出现文字。无字模式中，变化画框也不得出现任何字母、汉字、数字或伪文字。

## 7. 当前模式与壁纸

调用方会在本提示词后附上已经解析完成的唯一当前模式、准确尺寸、源图可见性和锁定文字。只执行附加块中的当前值，不要自行选择模式。

- 纯设计版与壁纸不显示源照片、分界线或摄影预留区。
- 每张壁纸都为目标宽高比重新构图。系统 UI 区域保持低信息，不绘制时钟、图标、Dock、控件或设备框。
- 连贯壁纸使用原照片锁定身份和内容，定调图只锁定简练造型、手绘线条、材料层级、色盘、留白、幽默尺度和文字气质；不得机械裁切或顺序垫图。

## 8. 生成前检查

1. 主体仍能通过至少三个源图专属线索被识别。
2. 只有一个来自源图的温和视觉隐喻或俏皮转译，没有通用卖萌元素。
3. 手绘线条与混合媒介有真实纸面误差，但主体依然清楚。
4. 构图轻盈、平衡、有大量呼吸空间，辅助符号都有作用。
5. 色盘高明度、低至中饱和且来自源图，一个互补跳色保持小面积。
6. 文字准确、自然、符合目标语言，并像画进插画而不是后贴图层。
7. 当前模式、尺寸、源图可见性、壁纸安全区和文字设置全部服从附加块。
8. 最终画面没有拼贴总览、Logo、水印、UI、样机、第二焦点或无关装饰。
