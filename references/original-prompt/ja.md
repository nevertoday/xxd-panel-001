# XXD Panel 001 原始プロンプト · 日本語訳

> 閲覧用の忠実な翻訳です。実行時の唯一の基準は[簡体字中国語の原文](zh-CN.md)です。

アップロードした写真は一枚ごとに独立したハイエンドなデザインポスターに仕上げてください。複数画像のコラージュにはせず、写真ごとに個別に出力します。全体は3:4の縦位置構図とし、上下二つの領域は高さを厳密に1:1、それぞれ画面の50%を占めます。

上半分は元の写真を残し、被写体の構造、リアルな質感、自然な光と影、元の色彩の雰囲気を保ち、わずかにハイエンドな写真的カラーグレーディングのみを施して、雑誌写真や美術展のような質感を与えます。画面比率に合わせるため、空・地面・周囲の背景を自然に拡張してもかまいませんが、被写体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分は写真の中で最も識別性の高い被写体、輪郭、姿勢、そして物語的な関係性を抽出し、軽やかで、稚拙で、レトロな手描きのエディトリアル・イラストレーションへ再構成します。細部を機械的に写し取るのではなく、造形を要約し、比率をやや誇張し、特徴を記号化し、ユーモラスな視覚的比喩によって表現し直しつつ、一目で元のものだと分かるようにしてください。スタイルはモダニズムのエディトリアル・イラスト、バウハウスの構成、絵本、ファッション・スケッチの気質を融合させ、形体は簡潔に、線は細く手仕事のわずかな狂いを含ませ、軽やかで、賢く、茶目っ気があり、それでいて抑制の効いたものにします。

配色は上部の写真から抽出し、高明度で低〜中程度の彩度の限られたパレットを用い、生成り色や淡い色の余白を大きく取り、少量の補色を視覚的なアクセントとして使います。水彩、グワッシュ、色鉛筆、パステルクレヨン、ドライブラシを混ぜた質感を用い、紙の粒子、ざらついた縁、白の透け、見当ズレ、不完全な筆致を残し、滑らかなベクター、写実的な光と影、3Dレンダリング、プラスチックのような質感は避けます。

全体の構図はバランスがよく、軽やかで、呼吸感のあるものとし、少量の手描きの線、幾何学的な記号、抽象的な要素を加えてもかまいません。文字はレトロな手書きのタイトル、番号、年号を少量用い、イラストに自然に溶け込ませます。全体として古いファッション絵本、旅のイラスト、アート出版物、ハイエンドなエディトリアル・デザインを参照し、優しく、レトロで、リラックスしていて、洒落ていて、ユーモラスで、少し不器用で風変わりな自信のある気質を示し、カートゥーン感、安っぽさ、EC感、そしてテンプレート
